How do I get a server?
  • This computer (Windows, macOS, Linux): install the NeuroClaw desktop app and open it. The address above is already right.
  • Chromebook: the engine cannot run inside a Chrome extension. Turn on Linux (Settings, Developers), install the NeuroClaw Linux package there, and start it; Chrome reaches it at http://localhost:7861.
  • Another computer on your network: run NeuroClaw there with a Remote Access password set, then type its address, for example http://192.168.1.20:7861, and sign in when asked.

Connecting to another computer asks Chrome for permission to talk to that one address. Nothing is sent anywhere else.
