Extension Builder — NeuroLang

Define named neurons with a value, a vale (resistance to change), and a contract/definition, then build them. The mesh evaluates each statement and returns the resulting neurons — every neuron is auto-wired all-to-all (weight 0.1) unless you override it. Syntax: name="x" creates a neuron; then "x"@value="0.9", "x"@vale="0.8", "x"@definition="text", and print "x".
