Extension Builder — NeuroLang

Define named neurons with a value, a vale (resistance to change), and a contract/definition, then Build to save them as a persistent extension on disk. Neurons are auto-wired all-to-all (weight 0.1) unless overridden. Syntax: name="x" creates a neuron; then "x"@value="0.9", "x"@vale="0.8", "x"@definition="text".
