# Project

A comprehensive AI/ASI system with modular architecture.

## Quick Start

```bash
# Installation
./scripts/install.sh

# Development
npm run dev

# Build
npm run build

# Test
npm test
```

## Project Structure

```
├── asi_core/              # Core ASI components
├── benchmarks/            # Performance benchmarks
├── config/                # Configuration files
├── desktop-app/           # Desktop application
├── dist/                  # Distribution builds
├── docs/                  # Documentation
│   ├── architecture/      # Architecture documents
│   ├── deployment/        # Deployment guides
│   ├── api/               # API documentation
│   └── self-improvement/  # Self-improvement plans
├── extension-builder/     # Extension building tools
├── interface/             # User interface components
├── model && skills manager/  # Model and skills management
├── models && skills/      # AI models and skills
├── plugin_manager/        # Plugin management system
├── plugins/               # System plugins
├── public/                # Public assets
├── robotic_organism/      # Robotics simulation
├── scripts/               # Build and utility scripts
├── src/                   # Source code
├── test/                  # Test files
└── tests/                 # Additional tests
    └── security/          # Security tests
```
